# Source: "How To Use Claude Better Than 99% Of People"

Sandeep Swadia, ~19.5 min. This is the workflow `CLAUDE.md`'s "crew" and
PRIME framework are adapted from. Kept here for reference, not as
instructions to follow directly — `CLAUDE.md` is the operative version.

## The 5 tools (his framing — separate apps)

1. **Think** (Claude Chat) — thinking partner for messy problems. Give it
   rich context (connected Drive/email/calendar), ground with real research,
   learn concepts in parallel while working.
2. **Remember** (Claude Projects) — persistent context across sessions:
   files, tone, instructions, ongoing work. Customize at the project level,
   not the account level, because different projects need different context.
3. **Execute** (Claude Cowork) — desktop app for multi-step tasks against
   local files, notably via **MCP connectors** to other tools (e.g. an ad
   generator) so Claude can act through other apps, not just talk about them.
4. **Build** (Claude Code) — plain-English software building; no CS
   background required, just clarity about the problem.
5. **Browse** (Claude for Chrome) — extension so Claude can see and act on
   whatever page you're looking at, in real time.

## PRIME — his prompting framework

- **P**urpose — precise goal for the output
- **R**esearch — grounding context/data, verified rather than assumed
- **I**nterview — tell Claude to ask clarifying questions before responding
- **M**echanics — desired output format/length/structure
- **E**xamples — show what "good" looks like

## Why `CLAUDE.md` diverges from this

The video's 5 items are 5 separate apps because that's how Claude ships to a
general consumer. Inside one Claude Code session, most of that is already
unified — one agent with tool access, skills, and memory. So `CLAUDE.md`
keeps PRIME as-is but reframes the 5 tools as 8 phases of one workflow loop
(adding Research, Plan, Verify, Document as explicit steps), each backed by
an actual installed capability (a `superpowers` skill or a Claude Code tool)
rather than a separate app to open.
